What it does

Three things it does exceptionally well.

No dashboards to check. It sits in your menu bar and tells you exactly what changed.

Tracks the right PRs

Automatically pulls in PRs assigned to you, PRs where your review is requested, and — toggleable — PRs you authored. Paste a link, owner/repo#123, or a git ref to watch anything else.

Only pings on a transition

A PR is never announced the first time GitWall sees it — only when its state actually changes underneath you: changes requested, your review requested, approved, CI failing, merged, closed.

Grouped, ordered, remembered

PRs sit under their repo; repos sort by the loudest PR inside so what needs attention floats to the top. Collapse a repo header and it stays collapsed across restarts.

Colour means one thing

Whose move it is, at a glance.

Repo headers carry up to two badges — red for changes you owe, yellow for reviews you owe. The menu-bar count is only the red ones.

Changes requestedA reviewer asked for changes and hasn't been re-requested yet.
Awaiting reviewReviewers are assigned but haven't ruled — the ball's in their court.
ApprovedReady to merge, as far as review is concerned.
Working on itYou've marked the fix as pushed — muted until new review activity lands.
Everything elseCommented, draft, or no reviewers yet.
How it works

Build it once. It polls quietly in the background.

01

Sign in

Picks up your gh CLI token automatically, or paste a personal access token with repo scope. Stored in the login Keychain — never on disk.

02

It polls in the background

Every 120s by default (30s–30min in settings). Each poll costs a handful of GitHub API calls, well inside normal rate limits.

03

Act only when pinged

Click a notification to jump straight to the PR on GitHub. Mark it "working on it" once you've pushed a fix, or ignore it entirely.

Install

Build from source — it's a two-minute build.

No Homebrew tap yet, so GitWall is installed by building the Swift package locally.

1
Prerequisites

macOS 14 or later, and Xcode 16+ (or the Swift 6 command line tools) for swift build.

2
Clone and build

Builds a universal (arm64 + x86_64) GitWall.app and copies it to /Applications.

git clone https://github.com/Vahsir7/GitWall.git cd GitWall chmod +x build.sh ./build.sh --install
3
Launch and sign in

Open GitWall from /Applications — it appears in the menu bar with no Dock icon. If the gh CLI is installed and logged in, it authenticates automatically; otherwise open the gear icon and paste a personal access token.

4
Optional: start at login

System Settings → General → Login Items → add GitWall.
